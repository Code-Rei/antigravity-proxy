API Usage & Client Integration

Use this proxy with Cursor, OpenCode, VS Code, Python SDK, or cURL.

OpenAI SDK (Python) - Nano Banana 2

from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="sk-antigravity"
)

# Generate with Nano Banana 2
response = client.images.generate(
    model="nano-banana-2",
    prompt="A futuristic glass skyscraper in a lush forest",
    size="1024x1024",
    response_format="url" # or "b64_json"
)

print(response.data[0].url)
